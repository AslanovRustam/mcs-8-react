# Заняття 8 - Мемоізація, рефи, контекст

- Мемоізація обчислень з хуком `useMemo`
- Рефи з хуком `useRef`
  - Створення
  - Життєвий цикл рефа
  - Рефи як контейнери значень
- Контекст
  - Створення контекста з `createContext`
  - Хук `use`
  - Кастомний компонент провайдера `ThemeProvider`
  - Стан та зміна стану у компоненті провайдера `ThemeProvider`
  - Передача стану та сеттера через контекст
